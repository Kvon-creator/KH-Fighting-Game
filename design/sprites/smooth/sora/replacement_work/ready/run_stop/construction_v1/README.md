# New articulated run-stop construction, not finished art

Eight poses now exist: reviewed running entry, braking reach, heel contact, knee compression, rear-foot catch-up, carry lowering, guard settling and approved standing guard. Middle poses use newly drawn thigh/shin volumes with independent joints, retained boot/upper-body parts and a rigid weapon projection. No full body was scaled, and start was not reversed.

This is an anatomical construction prototype. Shorts/shins are simple placeholder drawings; anatomy, cutout seams, upper-body perspective, fingers, chain and the final guard seam require substantial manual art refinement. The source boot crop needs trimming. These outputs are not game-ready sprites or final smooth art. Do not integrate into Godot.

Each pose's actual joint coordinates, upper-body pitch, hand anchor, weapon camera and durations are in manifest.json. Original sprites remain intact. PNGs, a sheet, contact sheet and GIF are supplied for construction review only.
