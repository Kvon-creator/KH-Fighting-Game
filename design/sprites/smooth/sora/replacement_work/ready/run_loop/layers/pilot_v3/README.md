# Refined local carry pilot

Open Refinement_Comparison.png for previous and revised upper-body reconstruction. This version uses smooth sampled curves for the local jacket, sleeves, bent carrying arm and free arm. The old near forearm is removed to avoid retaining a second arm pose. Finger placement is derived from the same projection as the handle.

Weapon master, physical length, camera yaw and grip anchor remain unchanged from pilot_v2. Body and leg pose are retained; local torso shading and shoulder/sleeve contours support the raised carrying arm. Source sheets and earlier pilots are preserved. All layers remain separately editable.

The rebuilt jacket details still differ from the original painted artwork and need art review. Shoulder contact and anatomical perspective are visually approximate, not a measured 3D character rig. This is one refined frame, not a full animation, installed replacement or Godot test. Remaining frames require individual pose registration and local repairs; they must not be manufactured by scaling this body image.
