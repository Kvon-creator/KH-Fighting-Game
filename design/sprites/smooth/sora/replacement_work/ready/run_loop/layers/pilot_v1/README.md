# Rigid weapon construction pilot

One locally composited run-loop frame, built with Python/Pillow; no image generation. Open Comparison.png for original / construction pilot / anchor overlay.

Original run-start and run-loop SHA-256 hashes match the preservation plan. Source sheets are untouched. Preview is 512 x 512 RGBA with actual transparency. All weapon parts come from one master transformed as a unit; head and fingers are separate foreground layers. Body-clean plate, reconstruction, removal mask, arm, weapon instance, master, chain, fingers and head overlap are retained individually. manifest.json records the grip, angle, scale and rigid anchors.

This is a construction review, not finished sprite art. The chest and raised forearm repairs are visibly simpler than the approved artwork. The pilot weapon silhouette, length, grip, anatomical arm identity and shoulder contact need review before drawing the remaining frames. Chain/charm are also simplified. No animation playback, replacement installation or Godot integration is claimed.

Next step: refine the torso/arm linework and shoulder fit on this one frame, then reuse the approved master on the remaining frames with per-frame anchors and masks.
