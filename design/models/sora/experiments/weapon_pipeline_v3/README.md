# Crown profile from the user's weapon reference

Current files: [kingdom_key_reference_crown.blend](kingdom_key_reference_crown.blend), [kingdom_key_reference_crown.glb](kingdom_key_reference_crown.glb), [whole weapon](reference_crown_front.png) and [blade-head close-up](reference_crown_detail.png). [Review.html](Review.html) shows the revised shape. Earlier triangular and square-tooth constructions remain preserved in v1/v2; they are superseded for this review.

The newest reference is the user's attached640x640 image of a diagonal Kingdom Key. It was supplied as an image, not an actual mesh file. The new blade head follows its slanted outer prongs, pointed recesses and two rounded inner projections. Approximate image-space landmarks and the transformation into the weapon's local plane are in [crown_reference_trace.json](crown_reference_trace.json). This is a procedural interpretation for review, not a recovered original model or an exact measurement from multiple views.

The final hidden crown root extends into the shaft to prevent a floating gap. The first trace used the visible cylinder edge in the image; `weapon_pipeline_pilot.blend`, its original GLB and initial renders are preserved diagnostics before that connection correction. Use the `kingdom_key_reference_crown` files above. The handle/collars/shaft keep one axis and24 meshes share one rigid root. The chain remains rigid in this pilot. Sora's actual shoulder carry, hand attachment and foreground tip motion still need a character rig.

The `.blend` retains the procedural cel shader. The GLB uses simple palette materials for exchange; it does not carry the full Blender shader. [Reference_Crown_QA.json](Reference_Crown_QA.json) records the root correction and hashes. [Reference_Final_Scene_QA.json](Reference_Final_Scene_QA.json) checks the reopened final scene, transparent full-weapon render, rigid axis/root and four exported palette colors. Close-up images intentionally crop the shaft and are for shape review.

The guard, wrap, hardware and pendant remain preliminary. This update specifically corrects the crown profile against the new reference; it does not establish final artwork approval, a completed Sora character or gameplay integration. All original2D sprite work is preserved.
