# KH-Fighting-Game

A Kingdom Hearts fighting game made in Godot 4.7.2 (project in `KingdomArena/`).

## Controller support

> **Disclaimer:** Only the **PlayStation 5 DualSense** controller has been tested with this game. Other controllers
> (Xbox, Switch Pro, generic or third-party gamepads) may work, but their buttons could be mapped differently or not
> respond at all. In the browser version (GitHub Pages), press any button on the controller once so the browser can
> detect it; Chrome and Edge are the browsers it was tested with.

Keyboard controls work without a controller.
