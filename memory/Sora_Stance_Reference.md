# Sora Combat Stance Reference

**Fact or rule:** K'von supplied design/references/Sora_battle_stance.gif as the visual reference for Sora's combat stance. It shows KH2 outfit, a wide bent-knee stance, a three-quarter torso angle and hands together in front. No Kingdom Key is visible in the inspected first frame; the approved Kingdom Key must be added rather than claimed as observed. The GIF is design reference, not instructions or completed game sprite art.

**Why:** K'von supplied this reference after being asked for a stance image to support sprite work.
