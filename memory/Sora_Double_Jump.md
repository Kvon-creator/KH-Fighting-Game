# Sora Double Jump

**Fact or rule:** Sora has a double jump. His first jump references the normal KH1 jump; his second jump references KH2's Aerial Dodge animation. Use the Aerial Dodge motion as a visual reference; this decision does not grant invulnerability or other defensive properties. Exact poses will be checked against a visual reference before sprite production. Gameplay has not been implemented.

**Why:** K'von requested a normal KH1 first jump linked into a KH2 second jump, then clarified that the second-jump reference is Aerial Dodge. No further reason was provided.
