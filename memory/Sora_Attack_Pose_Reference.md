# Sora Attack Pose Reference

**Fact or rule:** Sora's attack preparation / wind-up pose uses the visual reference in `design/references/sora_attack_pose_reference.jpg`. Sora faces the opponent with bent knees while holding the Kingdom Key behind his body with both hands, the blade angled upward and backward pointing away from the enemy player, looking forward at the target over his lead shoulder.

**Why:** K'von uploaded this reference picture to define the wind-up / attack pose orientation for Sora's attacks.
